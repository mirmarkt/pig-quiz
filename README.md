## 这是什么

通过 60 道性格题 + 15 道关系偏好题，**给你匹配一只群友小猪**——比如「🐱🐷 黑猫猪」「🦁🐷 狮子猪」「🐰🐷 兔猪」。

每个小猪都有：
- **群内定位**（团宠 / 气氛组 / 技术大佬 / 治愈系 / 酷盖 / ...）
- **跟你聊天的最佳话术**（其他群友怎么跟你说话最有效）
- **🎮 群友能力值面板**（10 项能力：攻击性/共情力/领袖力/感性度/行动力/洞察力/社交力/自由度/神秘感/稳定度）
- **🎯 群内偏好**（0/1/灵活——以模糊化的方式呈现，不下定义）
- **最佳群搭子**（哪种小猪跟你最配）

## 设计原则

- **不直接给标签**：不出现 MBTI 字母、不预测性向、也不基于 MBTI 推测性向
- **能力值中性化**：把 4 维 MBTI 转换成 10 项游戏能力值（攻击性/共情力/...），更娱乐也更安全
- **0/1 偏好而非性向**：测的是"在关系里倾向主动还是被动"，不是性向本身
- **隐私第一**：所有数据只在浏览器，关页面就消失

## 隐私

- ✅ **不收集任何数据**——所有答案只存在你的浏览器里，关页面就消失
- ✅ **不调用任何 API**——纯静态页面，无后端，无数据库
- ✅ **没有跟踪脚本**——不接 Google Analytics、不接任何第三方
- ✅ **代码完全公开**——你想审计就直接看 `index.html`

## 免责声明

本测试**仅供娱乐和群友间的玩笑**，**不能替代专业心理评估**。
